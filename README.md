# 欧陆改革宗 · 约翰一书研读

静态页面。讲解约翰一书：道成了肉身，爱实行出来，生命可以知道。教会的领受把这封信与约翰福音、约翰二书、三书归于同一位作者（二书与三书自称长老）。传统地点是罗马亚细亚的以弗所，常见范围约公元 85–95 年，不钉死精确年份。页脚版本 v20261003。

正文是中文讲解，不是任何版权圣经译本的全文。不确定的王年标为约。硬锚点只有：公元前 722（亚述灭北国）、586（巴比伦灭南国）、539（古列与归回）、公元 70（圣殿被毁）。

## 页面里有什么

- 一句记忆：道成了肉身；爱实行出来；生命可以知道
- 整本圣经故事线（卡片，无交叉连线）
- 王与时代色块：联合王国、分裂、被掳、归回、基督、教会，以及这封信的位置
- 以弗所 / 爱琴海 / 亚细亚示意地图
- 三个试验：认信、爱、顺服
- 五章：前因、背景、写了什么、经文、圣约、信条编号、难点、应用、记忆句
- 难点：1:8–10 与 3:6，2:2 的全世界，5:16 至于死的罪
- 六周短记忆路径

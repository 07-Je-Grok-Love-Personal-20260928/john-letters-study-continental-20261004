# 欧陆改革宗 · 约翰书信研读

静态页面。讲解约翰一书、约翰二书、约翰三书。教会的领受把三封信与约翰福音归于同一位作者；二书与三书自称长老。传统地点是罗马亚细亚的以弗所一带，常见范围约公元 85–95 年，不钉死精确年份。页脚版本 v20261004-2。

正文是中文讲解，不是任何版权圣经译本的全文。蒙拣选的夫人保持两种读法：一间教会，或一位女主人。不把该犹、丢特腓、底米丢写成经文没有的传记。

## 页面里有什么

- 三句记忆：生命可以知道；真理与爱不可拆；接待弟兄，不许野心作主
- 紧的圣约框架：恩典之约、道成肉身、挽回祭、相交、确据
- 以弗所示意地图
- 三个试验（认信、爱、顺服）的色块
- 约翰一书五章，含 1:8–10 与 3:6、2:2 的全世界、5:16 至于死的罪
- 约翰二书：夫人与儿女、真理和爱、不可接待迷惑人的
- 约翰三书：该犹、丢特腓、底米丢，两扇门
- 四个角度：接待、牧养、良心、敬拜
- 六周短路径
